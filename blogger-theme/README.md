# PromptBox Neo — Blogger থিম

AI প্রম্পট ও কোড মার্কেটপ্লেস স্টাইলের Blogger থিম। ফাইল: `promptbox-theme.xml`

## ইনস্টল
1. Blogger → **Theme** → ▼ → **Backup** করে আগের থিম সেভ রাখুন।
2. **Edit HTML** → সব কোড মুছে `promptbox-theme.xml`-এর পুরো কোড পেস্ট করুন → **Save**।
3. **Settings → Posts → Max posts shown on main page = 6** দিন (স্ক্রিপ্ট নিজেও প্রতি পেজে ৬টা পোস্ট রাখে, তবে এটা দিলে পেজ দ্রুত লোড হয়)।
4. **Layout → Favicon** থেকে নিজের ফেভিকন দিতে পারেন (না দিলে বিল্ট-ইন SVG লোগো থাকবে)।

## যা কিছু এডিট করবেন — কোডের একদম উপরে `PB_CONFIG`
| কী | কাজ |
|---|---|
| `siteName`, `tagline`, `logoUrl` | ব্র্যান্ড |
| `whatsapp` | এডমিনের WhatsApp নম্বর (যেমন `8801712345678`) |
| `menu`, `courseLink`, `aiLabText` | হেডার মেনু |
| `payments` | bKash / Nagad / Binance নম্বর, ধরন, রং — যত খুশি যোগ করুন |
| `lock.defaultPrice`, `lock.masterPin`, `lock.pins` | প্রিমিয়াম দাম ও PIN |
| `verify.seconds`, `verify.tasks`, `verify.adHTML` | ভেরিফাই পপআপের টাস্ক ও অ্যাড |
| `ads.header / inPostTop / inPostEnd / sidebar` | অ্যাড স্লট (AdSense কোডও কাজ করবে) |
| `trust`, `reviews` | সাইডবার |
| `counter.api` | ভিউ/কপি কাউন্টার (নিচে দেখুন) |
| `pwa.icon192`, `pwa.icon512` | অ্যাপ আইকন (PNG) |

## লেবেল সিস্টেম
| লেবেল | ফলাফল |
|---|---|
| `lock` / `Lock` | প্রিমিয়াম লক স্ক্রিন (`tbp-root`): পেমেন্ট নম্বর, ভেরিফিকেশন ফর্ম → WhatsApp, PIN দিয়ে আনলক |
| `verify` / `VERIFY` | মানব যাচাই (অঙ্ক) + টাস্ক + অ্যাড কাউন্টডাউন পপআপ |
| `download` | কোড/লেখা Neon Code Box-এ দেখাবে: Copy, Download (.txt), AI Test |

একাধিক লেবেল একসাথে দেওয়া যায়, তখন আগে verify, তারপর lock চলবে।

**পোস্টে দাম ও PIN সেট করা** (HTML ভিউতে, পোস্টের যেকোনো জায়গায়):
```html
<span data-price="৳199"></span>
<span data-pin="4821"></span>
```
অথবা `PB_CONFIG.lock.pins`-এ `"পোস্ট-আইডি": "4821"` লিখুন।

**Download পোস্ট:** কোড `<pre>` ট্যাগে রাখলে প্রতিটা `<pre>` আলাদা বক্সে দেখাবে। `<pre>` না থাকলে পুরো পোস্টের লেখা একটা বক্সে চলে যাবে।

## Apps Store আর Website to App
**অ্যাপ যোগ করা:** নতুন পোস্ট লিখুন, টাইটেলে অ্যাপের নাম দিন আর লেবেল দিন `app`। পোস্টের HTML ভিউতে একদম উপরে এটা বসান:
```html
<div data-apk="https://drive.google.com/...APK-লিংক" data-icon="https://...icon.png" data-size="5 MB" data-version="1.0"></div>
```
- `data-icon` না দিলে পোস্টের প্রথম ছবিটাই আইকন হবে।
- `data-apk` না দিলে ইনস্টল বাটন অ্যাপের পোস্টটা খুলবে।
- `data-size` আর `data-version` না দিলেও চলবে।

**স্টোরের ঠিকানা:** `/search/label/app`। হেডারের "📱 Apps Store" ট্যাব এখানেই নিয়ে যায়। চাইলে আলাদা পেজও বানাতে পারেন: Pages → New page → HTML ভিউতে `<div id="pb-apps-store" data-full="1"></div>` লিখুন।

**ইনস্টল করলে যা হয়:** ভেরিফাই পপআপ আসে, তারপর APK ডাউনলোড শুরু হয় আর ইনস্টলের সংখ্যা এক বাড়ে। ভেরিফাই বন্ধ করতে `PB_CONFIG.apps.verify = false` দিন। একই ভিজিটরকে একবার ভেরিফাই করলে ব্রাউজার বন্ধ না করা পর্যন্ত আবার করতে হয় না।

**অ্যাপের পোস্ট পেজ:** উপরে আইকন, নাম, ইনস্টলের সংখ্যা আর ইনস্টল বাটনসহ একটা অ্যাপ কার্ড দেখায়।

**"🪄 Website to App" / "+ নিজের অ্যাপ বানান":** একটা অর্ডার ফর্ম খোলে। সেখানে নাম, WhatsApp, সাইটের লিংক, অ্যাপের নাম, কালার, আইকন, প্যাকেজ আর পেমেন্টের তথ্য নিয়ে WhatsApp-এ আপনার কাছে পাঠায়। প্যাকেজের নাম আর দাম বদলাবেন `PB_CONFIG.w2a.packages`-এ। অ্যাপ বানানো শেষ হলে উপরের নিয়মে `app` লেবেল দিয়ে পোস্ট করলেই অ্যাপটা স্টোরে চলে আসবে।

> APK ফাইল Blogger-এ রাখা যায় না। Google Drive, GitHub Releases বা MediaFire-এ আপলোড করে সরাসরি ডাউনলোডের লিংক দিন।

## ⚠️ জরুরি সীমাবদ্ধতা (সৎভাবে)
- **লক পুরোপুরি নিরাপদ না।** Blogger-এ কোনো সার্ভার নেই, তাই লক করা পোস্টের লেখা আর `data-pin` দুটোই পেজের সোর্স কোড আর ফিডে থেকে যায়। যে ইউজার একটু টেকনিক্যাল, সে চাইলে বের করে নিতে পারবে। আসল দামি জিনিস (ZIP, পুরো কোড) পোস্টে সরাসরি রাখবেন না। পোস্টে শুধু Google Drive বা MEGA লিংক রাখুন, আর PIN পাওয়ার পর লিংক শেয়ার করুন, অথবা লিংকটাই WhatsApp-এ পাঠিয়ে দিন। চাইলে **Settings → Site feed → Allow blog feed = Short** দিন।
- **Verify-এর টাস্ক** (সাবস্ক্রাইব, জয়েন) সত্যিই সম্পন্ন হয়েছে কিনা Blogger যাচাই করতে পারে না। এটা শুধু ক্লিক-থ্রু গেট।
- **ভিউ/কপি কাউন্টার** ফ্রি সার্ভিস `counterapi.dev` ব্যবহার করে, যাতে সব ভিজিটরের সম্মিলিত সংখ্যা দেখায়। সার্ভিসটা বন্ধ হলে বা `counter.api: ""` দিলে শুধু ঐ ব্রাউজারের লোকাল কাউন্ট দেখাবে।
- **PWA ইনস্টল বাটন:** থিম নিজে ম্যানিফেস্ট তৈরি করে দেয়। কিন্তু Blogger-এ `sw.js` (service worker) হোস্ট করা যায় না, তাই Chrome-এর অটো "Install" প্রম্পট সবসময় আসবে না। না এলে বাটনে ক্লিক করলে "Add to Home screen" করার নিয়ম দেখাবে।

## এই রকম সাইট থেকে Android অ্যাপ বানানো
promptbox.store-এর মতো সাইটগুলো সাধারণত একটা **ওয়েব-টু-অ্যাপ র‍্যাপার** ব্যবহার করে। মানে অ্যাপটা ভেতরে আপনার ওয়েবসাইটটাই খোলে।
1. **PWABuilder** (pwabuilder.com): সাইটের URL দিলে Android প্যাকেজ (TWA, `.aab`/`.apk`) বানিয়ে দেয়। Play Store-এ পাবলিশ করা যায়। সম্পূর্ণ ফ্রি।
2. **WebView অ্যাপ বিল্ডার** (Web2Apk, AppsGeyser, Median.co ইত্যাদি): URL দিয়ে APK বানানো যায়। এরপর APK-টা নিজের সাইটে ডাউনলোড লিংক হিসেবে দেওয়া যায় (Google Drive বা GitHub Releases-এ আপলোড করে)।
3. নিজে বানাতে চাইলে Android Studio-তে একটা WebView প্রজেক্ট খুলে সাইটের URL লোড করুন।

APK-টা নিজের সাইটে পাবলিশ করতে: একটা পোস্ট বা পেজ বানিয়ে APK-এর ডাউনলোড লিংক দিন, আর হেডারের 📲 বাটন দিয়ে PWA ইনস্টলের অপশনও রাখুন।
